# Code of Conduct

We want this project to be a welcoming place to discuss and improve the software.

## Expected behavior

- Be respectful and constructive, including when you disagree.
- Focus feedback on the work and explain it clearly.
- Respect other contributors' privacy and do not share their personal information without permission.

Harassment, threats, discriminatory abuse, and repeated disruptive behavior are not welcome. Maintainers may edit or remove comments, close threads, or restrict participation to keep project spaces usable.

For conduct concerns, use GitHub's reporting tools on the relevant comment or account. If you are comfortable discussing a project space issue publicly, open a repository issue without sharing private details. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
