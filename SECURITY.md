# Security policy

## Supported versions

Security fixes are considered for the latest code on the default branch. Older commits and forks are not maintained by this project.

## Reporting a vulnerability

Use **Security > Advisories > Report a vulnerability** on this repository to send a private report. Include steps to reproduce, the potential impact, and a suggested fix if you have one. Do not include live API tokens or unrelated personal data.

If the private reporting button is unavailable, open a public issue asking the repository maintainers to enable private vulnerability reporting or provide a private reporting channel. Do not disclose the vulnerability details in that issue.

Do not report security vulnerabilities through a public bug report.
